# Data Directory

## Bundled Sample (Default — Fast Repro)
- `sample/uber_tweets.csv` — synthetic Uber_Support thread tweets
- `sample/precedents.json` — resolved (customer, reply) pairs for retrieval

Generated by: `python scripts/generate_sample_data.py`

## Processed (Generated at Runtime)
- `processed/uber_threads.csv` — prepared tweet subsample
- `processed/precedents.json` — precedent pairs for embedding index
- `processed/data_meta.json` — metadata (source, counts)

Created by: `python scripts/prepare_data.py`

## Raw Kaggle Data (Optional)
Place `twcs.csv` from [Customer Support on Twitter](https://www.kaggle.com/datasets/thoughtvector/customer-support-on-twitter) at:
```
data/raw/twcs.csv
```

Then run:
```bash
python scripts/prepare_data.py --kaggle data/raw/twcs.csv
```

Raw data is gitignored (too large). Only processed subsamples and bundled samples are tracked.
